# 입시일정 · 우리반 입시 일정 관리

담임 교사가 반 공통 입시 일정과 학생별 입시 일정을 한 화면에서 관리하는 웹앱입니다.
`index.html` 파일 하나로 동작하며, 서버·로그인·외부 라이브러리가 필요 없습니다.

**🔗 바로 사용하기: https://mysunkim-debug.github.io/ipsi-schedule/**

## 기능
- 학생 추가·삭제, 명단 파일(CSV·TXT) 한 번에 올리기
- 일정 추가·수정·삭제 (반 공통 / 학생별)
- D-day 목록 보기와 월간 달력 보기, 학생별 필터
- 인쇄 (A4 가로)
- 데이터 백업(내보내기)·복원(불러오기)

## 사용 방법
위 사이트 주소로 접속하거나, `index.html`을 내려받아 더블클릭하면 브라우저에서 열립니다.
입력한 내용은 그 기기의 그 브라우저에만 저장되므로, 가끔 **내보내기**로 백업해 주세요.
(사이트 주소와 내려받은 파일은 저장 공간이 서로 달라 데이터가 공유되지 않습니다.)

> 예시 데이터(학생A, 가나대 등)는 모두 가상 자료입니다.

자세한 기획은 [PRD.md](PRD.md)를 참고하세요.

# ✏️ 단어 추가·수정하는 법 (직접 하기)

프로그램 설치 없이 **GitHub 웹사이트에서** 바로 고칠 수 있습니다.

1. https://github.com/mysunkim-debug/ipsi-schedule 에 로그인해서 들어갑니다.
2. 고칠 파일을 엽니다.
   - 국어 어휘 노트 → `vocab/index.html`
   - 수능 영어 어휘 → `suneung/index.html`
3. 오른쪽 위 **연필 모양(✏️ Edit this file)** 을 누릅니다.
4. `Ctrl + F`로 아래에 적은 목록 이름을 찾아, **목록 맨 아래**에 한 줄을 추가합니다.
5. 오른쪽 위 초록 버튼 **Commit changes…** → 다시 **Commit changes**를 누릅니다.
6. 1~2분 뒤 사이트를 새로고침하면 반영됩니다.

> ⚠️ **새 단어는 꼭 목록 맨 아래에 붙이세요.** 단어마다 순서대로 번호가 매겨져 학생 기기의 기록(외움·별표 등)과 연결됩니다. 중간에 끼우거나 기존 줄을 지우면 기록이 다른 단어로 옮겨 갑니다.
>
> 따옴표(`'` 또는 `"`), 쉼표(`,`), 대괄호(`[ ]`)를 빠뜨리면 앱이 아예 안 열립니다. **바로 위 줄을 복사해서 내용만 바꾸는 것**이 가장 안전합니다. 저장 후 앱이 안 열리면 방금 고친 줄을 다시 확인하세요.

## 📒 국어 어휘 노트 (`vocab/index.html`)

`const SEED = [` 목록의 맨 끝, `];` 바로 위에 추가합니다.

```js
  ['2026-10-17', '동', '사색하다', '思索', '어떤 것에 대하여 깊이 생각하고 이치를 따지다.', '숙고하다, 사유하다', '', '死色과 구별'],
```

순서: `['날짜', '품사', '단어', '한자', '뜻', '유의어', '반의어', '메모'],`

- 품사는 `명`, `동`, `형`, `부`, `기타` 중 하나
- 빈칸은 `''` 로 둡니다. 유의어·반의어가 여러 개면 쉼표로 구분
- **한자어는 한자 칸도 채워 주세요.** 새 한자는 `const HANJA` 표에도 `字:훈 음|` 형식으로 넣어야 한자를 눌렀을 때 뜻이 나옵니다. (예: `思:생각 사|索:찾을 색|`)
- 이미 학생 기기에 들어간 단어의 **뜻을 고치면, 그 기기에는 반영되지 않습니다** (기기에 저장된 사본을 씁니다). 새로 여는 기기에만 적용되니, 기존 학생에게는 앱의 수정 버튼으로 직접 고치게 안내하세요.

## 📘 수능 영어 어휘 (`suneung/index.html`)

이 앱은 고친 내용이 **모든 기기에 바로 반영**됩니다. (기존 단어의 뜻 수정도 OK)

**고빈출 단어** — `const JL = [` 목록의 마지막 줄 `[400, ... ]];` 뒤에 붙입니다. 마지막 `]];` 를 `],` 로 바꾸고 새 줄 끝을 `]];` 로 닫습니다.

```js
[400,"yield","산출하다, 낳다; 굴복하다, 양보하다"],
[401,"새 단어","뜻 (파생어: 뜻) ★ 다의어 뜻"]];
```

순서: `[번호, "단어", "뜻"]` — 번호는 이어서 매깁니다. 401번부터는 학습 범위에 `Day 9` 같은 묶음이 없으니 "고빈출 400 — 전체"에서 보입니다.

**6/9모·새 시험 어휘** — `const MO = [` 목록의 맨 끝, `];` 바로 위에 추가합니다.

```js
["주석","9모","overwhelm","압도하다","파생어 등 참고 메모","[9모] 41번 (장문 제목)"],
```

순서: `["분류", "세부", "단어", "뜻", "참고(기본 의미·파생어)", "출처·예문"]`

- 분류는 `공통`, `다의어`, `관용어구`, `연결어`, `주석` 중 하나 (학습 범위 메뉴가 이 이름으로 묶습니다)
- 세부는 자유롭게 (예: `동사류`, `6모 단독`, `양보`). 없으면 `""`
- 줄바꿈은 `\n` 으로 씁니다. (예: `"[6모] 20번\n[9모] 20번"`)
